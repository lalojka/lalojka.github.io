How V4 API EPM Works

Connect your WhatsApp Business number to the WhatsApp Cloud API and manage all conversations from a single dashboard.

🔗

1. Connect via Embedded Signup

Link your WhatsApp Business number to V4 API EPM using Meta's Embedded Signup. Takes under 2 minutes.

💬

2. Automate with templates

Send pre-approved message templates, assign conversations to agents, and set up automated follow-ups.

📊

3. Track in one dashboard

All incoming and outgoing messages appear in the V4 API EPM dashboard. Multiple agents, one number.

Who is V4 API EPM for?

V4 API EPM is designed for SMBs and agencies that want to scale their WhatsApp Business operations without managing multiple phone numbers or apps.

Typical case: a 3-person sales team. All agents use the CRM to respond, assign chats, and send product catalogs. One verified number, multiple agents working simultaneously.

  • Send approved templates from CRM to any customer
  • Assign incoming chats to the right agent automatically
  • Unified conversation history: one number, full team access

Typical workflow

1 Customer sends a message to your WhatsApp number
2 CRM receives it and assigns to the available agent
3 Agent replies from CRM using an approved template

WhatsApp Cloud API Capabilities

V4 API EPM uses the WhatsApp Business Platform (Cloud API) to send and receive messages on behalf of your business.

✅ Supported via API ⚠️ Requires Approved Templates
1:1 messages within the 24-hour service window Proactive messages outside 24h window require pre-approved templates
Text, images, documents, and audio messages No broadcast to multiple users simultaneously
Message status: sent, delivered, read Template messages must be approved by Meta before use
Webhooks for all incoming messages Marketing templates require opt-in from the customer
ℹ️ Template policy: All business-initiated conversations outside the 24-hour service window require pre-approved templates per WhatsApp Business Policy.
